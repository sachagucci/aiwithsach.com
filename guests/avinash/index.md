# Avinash

Avinash (Co-founder and technical lead, Cactus (Y Combinator batch)) was a guest on AI with Sach, a podcast hosted by Sacha Gucciardo in Montréal.

## Episode 29: Building Cactus: AI That Actually Helps Solopreneurs (June 2025)

Cactus co-founders explain how a personal need for private chefs led them to build an AI assistant for solopreneurs, and why they build slowly.

Page: https://aiwithsach.com/episodes/29-building-cactus-ai-that-actually-helps-solopreneur/

> I think the hardest piece has been actually finding what exactly is it that our customers need. Again, not what, need. So what is it that our customer, what is it that we can provide to our customers that gives them a lot of value? I think that has been more harder than actually building it because these days with AI, you can literally build anything.

> Yeah, I have a controversial answer to this as well, which is don't build AI tools for or tools in general. If you're optimizing for investors and not talking to users, I think you as a founder have already lost, unfortunately.

> So instead of building multiple small microservices, writing APIs to connect them all together, the way I'm looking at it is building one big monolithic software using Ruby on Rails, which is again, for most people is unconventional, but I'm optimizing for what we call developer happiness, which means that you end up shipping faster
> — at 3:14 (https://www.youtube.com/watch?v=PY8qVlbYHjU&t=194s)

> when you talk to a lot of users, a lot of customers, which everyone should be doing, you start to see patterns, right? So rather than building for each customer, you group this patterns together and you might come up with a much better implementation that works for a larger audience.
